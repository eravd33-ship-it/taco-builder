# כתוביות חיות

אפליקציית ווב לטלפון שמקשיבה לדיבור ומציגה אותו בתור כתוביות גדולות בעברית, תוך שניות. בלי התקנה, בלי הרשמה, בלי שרת.

**כתובת:** https://eravd33-ship-it.github.io/taco-builder/live/

פותחים בטלפון, בוחרים את שפת הדיבור, לוחצים על המיקרופון ומקרבים את הטלפון למי שמדבר. ב-Android אפשר לבחור בתפריט של Chrome "הוספה למסך הבית", וב-iPhone דרך כפתור השיתוף של Safari, ואז היא נפתחת כמו אפליקציה.

## מה יש בה

- כתוביות עברית גדולות, עם הטקסט המקורי מתחתן (אפשר להסתיר), ושורות ישנות שמתעממות.
- 17 שפות דיבור: אנגלית, ערבית, רוסית, צרפתית, ספרדית ועוד. מחליפים שפה תוך כדי האזנה.
- הגדלה והקטנה של הכתוביות, והמסך נשאר דלוק בזמן ההאזנה.
- תמלול מלא עם העתקה ושמירה לקובץ.
- הדגמה שלא צריכה מיקרופון ולא אינטרנט.
- נפתחת גם בלי חיבור (המסך עצמו), אבל זיהוי הדיבור והתרגום צריכים אינטרנט.

## איך זה עובד

```
מיקרופון → זיהוי דיבור של הדפדפן → תרגום לעברית → כתוביות
```

| קובץ | תפקיד |
| --- | --- |
| `speech.js` | עוטף את זיהוי הדיבור של הדפדפן: ממשיך להאזין אחרי כל הפסקה, מסנן תוצאות שחוזרות פעמיים, ומדווח על תקלות |
| `translate.js` | התרגום, עם מעבר אוטומטי בין מנועים (למטה) |
| `captions.js` | המודל של הכתוביות: שורות גמורות, והשורה שנאמרת עכשיו |
| `app.js`, `index.html`, `style.css` | המסך |
| `sw.js`, `manifest.webmanifest`, `icons/` | התקנה למסך הבית ופתיחה בלי חיבור |

### מנועי תרגום

ברירת המחדל "אוטומטי" מנסה לפי הסדר, ועוברת למנוע הבא אם משהו נכשל:

1. **במכשיר:** המתרגם המובנה של Chrome. חינמי, פרטי ובלי מכסה, אבל זמין רק בגרסאות של Chrome שכוללות אותו, והמודל מתחיל להוריד בלחיצה הראשונה על המיקרופון. עד שהוא מוכן התרגום עובר למנוע הבא.
2. **Google Cloud Translation:** אם הוזן מפתח בהגדרות. המפתח נשמר רק בטלפון.
3. **MyMemory:** שירות חינמי בלי מפתח, עם מכסה יומית קטנה, ובהאזנה רצופה היא יכולה להיגמר תוך זמן קצר. כשהמכסה נגמרת מוצג הטקסט המקורי והאפליקציה אומרת את זה.

אפשר לבחור מנוע אחד בהגדרות. "תרגום מהיר תוך כדי דיבור" מתרגם גם את המשפט שעוד לא נגמר. במנוע שבמכשיר זה פועל תמיד, ובמנועים שבאינטרנט זה מכפיל את הצריכה, ולכן כבוי כברירת מחדל.

## מגבלות

- היא שומעת דרך **המיקרופון** בלבד. דפדפן לא יכול ללכוד את הקול שהטלפון עצמו מנגן, ולכן לתרגום סרטון שרץ באותו טלפון צריך להגביר את הקול ולהצמיד את המיקרופון לרמקול, או לשים את הסרטון על מכשיר אחר.
- זיהוי הדיבור הוא של הדפדפן: **Chrome** ב-Android, **Safari** ב-iPhone. ב-Firefox ובדפדפנים שבתוך אפליקציות (אינסטגרם, פייסבוק) הוא לא קיים, והאפליקציה אומרת את זה.
- איכות הכתוביות תלויה באיכות הזיהוי: רעש, דיבור מהיר או כמה אנשים יחד מורידים אותה.

## פרטיות

אין שרת של האפליקציה ושום דבר לא נשמר אצלנו. ההגדרות והמפתח נשמרים רק בדפדפן שלך. הקול נשלח לשירות זיהוי הדיבור של הדפדפן (Google ב-Chrome, Apple ב-Safari), והטקסט נשלח לשירות התרגום שנבחר, אלא אם התרגום מתבצע במכשיר.

## בדיקות

```bash
cd live
npm test                 # בדיקות יחידה (Node 22 ומעלה, בלי תלויות)
```

בדיקת דפדפן מלאה בגודל של טלפון, עם זיהוי דיבור ותרגום מדומים (צריכה Playwright):

```bash
npm i -g playwright && npx playwright install chromium
NODE_PATH=$(npm root -g) node tests/e2e.cjs צילומי-מסך   # אפשר בלי התיקייה, אז לא נשמרים צילומים
```

## הרצה מקומית

```bash
cd ..   # שורש הריפו
python3 -m http.server 8000
```

ואז לפתוח http://localhost:8000/live/. מיקרופון עובד ב-`localhost` וב-HTTPS בלבד.
