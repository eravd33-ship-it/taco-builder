# 🎬 Creator Bot – העוזר האישי לערוץ היוטיוב

בוט טלגרם שמנהל איתך את הערוץ: מתזמן כל סרטון (צילום ← עריכה ← העלאה), שולח תזכורות בזמן,
דוחף אותך קדימה עם מוטיבציה ויעדים, שומר רעיונות, ומחבר את הכל לגוגל דרייב וליוטיוב.

## למה בוט טלגרם?

- **פושים אמיתיים בחינם** – ההודעות מגיעות לטלפון ולמחשב כמו הודעה מחבר, בלי לבנות אפליקציה.
- **ממשק נוח בעברית** – תפריט כפתורים קבוע, וסימון "✅ בוצע" או "⏰ מחר" בלחיצה אחת.
- **נגיש מכל מקום** – טלפון, מחשב, טאבלט. אין מה להתקין חוץ מטלגרם.
- **מודולרי** – כל פיצ'ר הוא קובץ אחד. מוסיפים פיצ'ר בלי לגעת בשאר (ראה [הוספת פיצ'ר](#-הוספת-פיצר-חדש)).

## מה הבוט עושה

| | פיצ'ר | מה קורה |
|---|---|---|
| 🎬 | **תזמון סרטונים** | נותנים שם ותאריך פרסום, והבוט מתזמן אחורה: צילום 4 ימים לפני, עריכה יומיים לפני, העלאה ביום הפרסום. |
| 🔔 | **תזכורות** | כל בוקר: מה צריך לעשות היום (כולל מה שבאיחור). כל ערב: צ'ק-אין על מה שנשאר פתוח. |
| 🔁 | **משימות קבועות** | "להגיב לתגובות" כל יום, "פוסט בקהילה" בימי שני וכו'. בוחרים ימים בכפתורים. |
| 💪 | **מנוע מוטיבציה** | משפט מוטיבציה יומי, מחמאה על כל שלב שהושלם, חגיגה על כל העלאה, ספירת רצף שבועות, ודחיפה עדינה כשמפגרים אחרי היעד או כשלא הייתה פעילות כמה ימים. |
| 🎯 | **יעדים** | יעד העלאות שבועי ויעד צפיות חודשי, עם פס התקדמות. |
| 💡 | **רעיונות** | כל טקסט ששולחים לבוט אפשר לשמור כרעיון, ובלחיצה להפוך אותו לסרטון מתוזמן. |
| 📈 | **נתוני ערוץ** *(לא חובה)* | צפיות ומנויים כל בוקר, וחגיגה כשעוברים אבן דרך (100 מנויים, 10,000 צפיות…). |
| 📁 | **גוגל דרייב** *(לא חובה)* | לכל סרטון חדש נפתחת תיקייה עם "חומרי גלם", "עריכה" ו"תמונה ממוזערת", וכל לילה הנתונים מגובים לדרייב. |

## 🚀 הפעלה ראשונה (בערך 5 דקות)

1. **יוצרים בוט בטלגרם:** פותחים שיחה עם [@BotFather](https://t.me/BotFather), שולחים `/newbot`, בוחרים שם, ומעתיקים את ה-**token**.
2. **מתקינים** (צריך Python 3.10 ומעלה):
   ```bash
   cd creator-bot
   python -m venv .venv
   source .venv/bin/activate        # ב-Windows:  .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. **מגדירים:** מעתיקים את `.env.example` ל-`.env` ומדביקים את הטוקן בשורה `TELEGRAM_BOT_TOKEN=`.
4. **מריצים:**
   ```bash
   python -m creator_bot
   ```
5. **מתחילים:** פותחים את הבוט בטלגרם ושולחים `/start`.
   🔒 מי ששולח `/start` ראשון הופך לבעלים של הבוט, וכל השאר נחסמים.

## ⏰ שהבוט ירוץ כל הזמן

כדי שהתזכורות יגיעו, הבוט צריך לרוץ כל הזמן. כמה אפשרויות:

- **המחשב שלך** – הכי פשוט להתחלה, אבל תזכורות יגיעו רק כשהמחשב דולק.
- **Raspberry Pi או מחשב ביתי שתמיד דלוק.**
- **שרת קטן בענן (VPS)** או כל שירות שמריץ קונטיינרים של Docker. הבוט צורך מעט מאוד משאבים.

עם Docker:

```bash
cd creator-bot
docker build -t creator-bot .
docker run -d --name creator-bot --restart unless-stopped \
  --env-file .env -v "$PWD/data:/app/data" creator-bot
```

הנתונים נשמרים בקובץ SQLite בתיקייה `data/`. כדאי לגבות אותו, או להפעיל את מודול הדרייב שעושה את זה אוטומטית.

## 📈 חיבור נתוני הערוץ (לא חובה)

1. נכנסים ל-[Google Cloud Console](https://console.cloud.google.com/), יוצרים פרויקט ומפעילים את **YouTube Data API v3**.
2. ב-**Credentials** יוצרים **API key**.
3. ב-`.env` ממלאים `YOUTUBE_API_KEY=...` ו-`YOUTUBE_CHANNEL=@הערוץ_שלך` (או מזהה ערוץ שמתחיל ב-`UC`).

הבוט שומר תמונת מצב פעם ביום. אחרי יום-יומיים מתחילים לראות שינויים, ויעד הצפיות החודשי מתחיל לעבוד.

## 📁 חיבור גוגל דרייב (לא חובה)

1. באותו פרויקט ב-Google Cloud מפעילים את **Google Drive API**.
2. מגדירים **OAuth consent screen** (User type: External) ומוסיפים את עצמך כ-Test user.
3. ב-**Credentials** יוצרים **OAuth client ID** מסוג **Desktop app**, ומעתיקים את ה-ID וה-Secret ל-`.env`.
4. מריצים פעם אחת (במחשב עם דפדפן):
   ```bash
   python -m creator_bot.tools.google_auth
   ```
   מאשרים בדפדפן ומעתיקים את השורה `GOOGLE_REFRESH_TOKEN=...` ל-`.env`.
5. **חשוב:** כשהאפליקציה במצב *Testing*, גוגל מבטלת את הטוקן אחרי 7 ימים. כדי שזה לא יקרה מעבירים אותה ל-**In production**
   (בהרשאה `drive.file` שבה הבוט משתמש לא אמור להידרש תהליך אימות של גוגל).

הבוט משתמש בהרשאה המצומצמת `drive.file`, כלומר הוא רואה **רק קבצים ותיקיות שהוא עצמו יצר**, ולא את שאר הדרייב שלך.
הוא יוצר תיקייה ראשית בשם "🎬 YouTube – Creator Bot". מותר להזיז אותה לכל מקום בדרייב.

## ⚙️ כל ההגדרות

| משתנה | ברירת מחדל | מה זה |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | – | **חובה.** הטוקן מ-BotFather |
| `TIMEZONE` | `Asia/Jerusalem` | אזור זמן |
| `MORNING_TIME` / `EVENING_TIME` | `09:00` / `20:30` | שעות הסיכום של הבוקר והצ'ק-אין של הערב |
| `WEEK_START` | `sunday` | תחילת השבוע (ליעד השבועי) |
| `UPLOADS_PER_WEEK` | `1` | יעד העלאות התחלתי (אפשר לשנות מהבוט) |
| `DB_PATH` | `data/creator_bot.db` | קובץ הנתונים |
| `OWNER_CHAT_ID` | ריק | נועל את הבוט על מזהה מסוים, במקום "הראשון ששולח /start" |
| `DISABLED_MODULES` | ריק | מודולים לכיבוי, למשל `ideas,routines` |
| `YOUTUBE_API_KEY`, `YOUTUBE_CHANNEL` | ריק | נתוני ערוץ |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REFRESH_TOKEN` | ריק | גוגל דרייב |

אפשר לשנות את משפטי המוטיבציה ב-`creator_bot/modules/motivation_texts.py`,
ואת שלבי ההפקה (למשל להוסיף שלב "תסריט" או "תמונה ממוזערת") ברשימה `STEPS` בקובץ `creator_bot/modules/videos.py`.

## 🧩 איך זה בנוי

```
creator_bot/
├── core/            # התשתית – לא יודעת כלום על סרטונים או יעדים
│   ├── app.py       #   בעלים, תפריט, ניתוב כפתורים, סיכום בוקר/ערב, תזמון
│   ├── module.py    #   מחלקת הבסיס שכל פיצ'ר יורש ממנה
│   ├── events.py    #   אירועים בין מודולים (video.published וכו')
│   ├── dates.py     #   הבנת תאריכים בעברית ("מחר", "יום חמישי", "25.10")
│   └── ui.py        #   עיצוב הודעות ועזרים לכפתורים
├── modules/         # הפיצ'רים – כל אחד עצמאי
│   ├── videos.py         🎬 תזמון סרטונים
│   ├── routines.py       🔁 משימות קבועות
│   ├── motivation.py     💪 מוטיבציה ויעדים
│   ├── ideas.py          💡 רעיונות
│   ├── youtube_stats.py  📈 נתוני ערוץ
│   └── drive.py          📁 גוגל דרייב
├── storage.py       # SQLite. כל מודול מנהל את הטבלאות שלו
└── tools/google_auth.py
```

כל מודול יכול להוסיף לעצמו כפתורים לתפריט, פקודות, משימות מתוזמנות, טבלאות במסד הנתונים, ושורות לסיכום הבוקר והערב.
מודולים מדברים ביניהם דרך **אירועים**, לא דרך קריאות ישירות. לדוגמה: מודול הסרטונים משדר `video.published`,
ומודול המוטיבציה מאזין ושולח חגיגה. ככה מוסיפים פיצ'ר בלי לשבור את מה שכבר קיים.

| אירוע | מתי |
|---|---|
| `video.created(video, idea_id)` | תוכנן סרטון חדש |
| `video.step_done(video, step, next_step)` | הושלם שלב (צילום/עריכה/העלאה) |
| `video.published(video)` | הסרטון עלה |
| `routine.done(routine, day)` | בוצעה משימה קבועה |
| `channel.milestone(metric, value)` | הערוץ עבר אבן דרך |

## ➕ הוספת פיצ'ר חדש

יוצרים קובץ ב-`creator_bot/modules/`, לדוגמה מודול שמציע לחתוך שורט מכל סרטון שעלה:

```python
# creator_bot/modules/shorts.py
from ..core import ui
from ..core.module import MenuButton, Module


class ShortsModule(Module):
    name = "shorts"

    def setup(self):
        self.core.events.on("video.published", self.suggest_short)

    def menu_buttons(self):
        return [MenuButton("📱 שורטס", self.show, order=35)]

    async def show(self, update, context):
        await ui.reply(update, "📱 כאן יופיעו רעיונות לשורטס")

    async def suggest_short(self, video, **_):
        await self.core.notify(f"📱 טיפ: לחתוך שורט מתוך <b>{ui.esc(video.title)}</b> ולהביא לו עוד צפיות!")
```

ומוסיפים את `ShortsModule` לרשימה `ALL_MODULES` בקובץ `creator_bot/modules/__init__.py`. זהו.

**רעיונות להמשך:** סנכרון עם Google Calendar, זיהוי אוטומטי של סרטון שעלה ביוטיוב (ואז סימון שלב ההעלאה),
דוח חודשי עם גרפים, הצעות לכותרות ולתמונות ממוזערות בעזרת AI, ודשבורד ווב.
