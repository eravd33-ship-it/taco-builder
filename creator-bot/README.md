## 🖥️ אפליקציה למחשב – Creator Desk

חלון עם **היום · סרטונים · משימות קבועות · רעיונות · יעדים · הגדרות**: מתזמנים סרטון בשם ותאריך,
מסמנים "✅ בוצע" או "⏰ מחר", ומקבלים תזכורת קופצת בבוקר ובערב, משפטי מוטיבציה וחגיגה על כל העלאה.
אחרי ההתקנה הכל עובד **בלי אינטרנט, בלי טלגרם ובלי הגדרות**. החיבורים ליוטיוב ולדרייב הם אופציונליים.

### הפעלה
צריך [Python 3.10 ומעלה](https://www.python.org/downloads/) (בהתקנה ב-Windows לסמן **Add python.exe to PATH**).
אחר כך:

| מערכת | מה עושים |
|---|---|
| **Windows** | לחיצה כפולה על `Creator Desk.bat` |
| **macOS** | לחיצה כפולה על `Creator Desk.command` (בפעם הראשונה: קליק ימני ← Open) |
| **Linux** | `./creator-desk.sh` |

ההפעלה הראשונה לוקחת כדקה, כי היא מתקינה את מה שצריך בתיקייה פרטית (`.venv`). אחר כך האפליקציה נפתחת מיד.
אם אין חלון מקומי (למשל ב-Linux), היא נפתחת בדפדפן. זה אותו ממשק ואותן יכולות.

**רוצה אפליקציה עצמאית בלי Python?** יש שתי דרכים:
- **להוריד מוכנה מגיטהאב:** נכנסים ל-**Actions** בריפו, פותחים את הריצה האחרונה של **Build desktop app**, ובתחתית הדף, בחלק **Artifacts**, מורידים
  `Creator-Desk-Windows` או `Creator-Desk-macOS`. מחלצים ופותחים את `Creator Desk` (ב-Windows קובץ `.exe`).
  הקובץ לא חתום, ולכן Windows עשוי להציג "Windows protected your PC": **More info ← Run anyway**. ב-Mac: קליק ימני ← **Open**.
- **לבנות בעצמך:** `pip install pyinstaller` ואז `python build_desktop.py`. תקבל תיקייה ב-`dist/` (או `Creator Desk.app` ב-Mac).
  הבנייה מתאימה למערכת שבה מריצים אותה.

### הסמל של האפליקציה
האפליקציה מגיעה עם סמל של "נגן" אדום בסגנון ערוץ וידאו (קובץ ה-`.exe`, אפליקציית ה-Mac, הלשונית בדפדפן והלוגו בתוך החלון).
זה סמל מקורי ולא הלוגו הרשמי של יוטיוב, שהוא סימן מסחרי רשום. **רוצה את תמונת הערוץ שלך כסמל?**
שומרים אותה כקובץ PNG, ואז: `pip install pillow` ו-`python packaging/make_icons.py --source my-logo.png` ואחר כך בונים מחדש.

### איך התזכורות עובדות
- **סיכום בוקר** (09:00) עם המשימות להיום, ו**צ'ק-אין ערב** (20:30) עם מה שנשאר פתוח. השעות משתנות ב*הגדרות*.
- ההתראות מופיעות כחלון קופץ של המערכת, ונשמרות גם ב-🔔 בתוך האפליקציה.
- כשהחלון פתוח לפניך, לא קופץ חלון של המערכת. תראה את ההודעה בתוך האפליקציה.
- **האפליקציה צריכה להיות פתוחה** כדי לשלוח תזכורות. אפשר למזער אותה. כדי שזה יקרה מעצמו, ב*הגדרות* מפעילים
  **"הפעלה אוטומטית עם המחשב"** והיא תיפתח ממוזערת בכל כניסה למחשב.
- פותחים אותה מאוחר? היא תשלח את הסיכום שפספסה. הלחצן **"שלח התראת בדיקה"** ב*הגדרות* בודק שהחלון הקופץ עובד.

### הנתונים והחיבורים
- הנתונים נשמרים בקובץ אחד בתיקיית הנתונים של המשתמש, והנתיב מופיע ב*הגדרות*
  (`%APPDATA%\CreatorDesk` ב-Windows, `~/Library/Application Support/CreatorDesk` ב-Mac, `~/.local/share/CreatorDesk` ב-Linux).
  מעתיקים את הקובץ כדי לגבות או לעבור מחשב.
- **חיבור ליוטיוב ולדרייב, מתוך האפליקציה:** ב*הגדרות* ← **חיבור לחשבון גוגל**. מכינים פעם אחת מזהה לקוח בחשבון הגוגל שלך
  (כ-5 דקות, חינם, ההסבר צעד אחר צעד נמצא שם באפליקציה, עם קישורים), מדביקים אותו ולוחצים **התחבר לגוגל**.
  נפתח הדפדפן, מאשרים, והאפליקציה מתעדכנת לבד: כרטיס נתוני הערוץ מופיע ב"היום", ולכל סרטון חדש נפתחת תיקייה בדרייב עם גיבוי יומי.
  אין צורך בקבצים ובשורת פקודה, ואין צורך בהפעלה מחדש. אפשר לנתק בכל רגע, ולהסיר את ההרשאה לגמרי ב-[myaccount.google.com/permissions](https://myaccount.google.com/permissions).
  האפליקציה מבקשת רק לקרוא את נתוני הערוץ ולנהל **קבצים שהיא עצמה יצרה** בדרייב, ולא את שאר הדרייב שלך. פרטי החיבור נשמרים בקובץ הנתונים בתיקיית המשתמש שלך, כמו קובץ `.env`.
  **טיפ:** במסך ההסכמה של גוגל לוחצים **Publish app**, אחרת החיבור יפוג אחרי 7 ימים.
  מי שמעדיף קובץ: אפשר גם להגדיר דרך `.env` עם אותם משתנים של הבוט, והוא גובר על החיבור מתוך האפליקציה.
- **שימוש גם בבוט?** מגדירים `DB_PATH` לאותו קובץ בשניהם, והם יראו את אותם סרטונים ויעדים. אז כדאי להשאיר רק אחד מהם עם תזכורות,
  כדי לא לקבל כל הודעה פעמיים.

### 🤖 העוזר (בינה מלאכותית)
מסך **עוזר** באפליקציה הוא צ'אט שמכיר את הערוץ שלך: הוא רואה את הסרטונים בתהליך, מה שפורסם לאחרונה, הרעיונות השמורים, היעדים
ונתוני הערוץ (אם חיברת יוטיוב), ולכן הוא עוזר לתכנן, מציע כותרות ועונה על שאלות. במסך **רעיונות** יש גם כפתור **הצע רעיונות**
(אפשר לכתוב נושא), ובלחיצה על "שמור" ההצעה נכנסת לרשימת הרעיונות שלך.

- **הפעלה:** מזינים מפתח API של Anthropic, במסך העוזר או בהגדרות (ההסבר צעד אחר צעד שם). המפתח נבדק לפני שהוא נשמר (הבדיקה בחינם).
- **עלות:** התשלום ל-Anthropic לפי שימוש, וכל תשובה עולה בדרך כלל כמה סנטים. החיוב נראה בחשבון שלך ב-console.anthropic.com. האפליקציה עצמה חינמית.
- **פרטיות:** מה שאתה כותב לעוזר, ורשימת הסרטונים, הרעיונות ונתוני הערוץ, נשלחים ל-Anthropic כדי שיוכל לענות. בלי להשתמש בעוזר לא נשלח שום דבר.
- **המודל:** Claude Opus 5.5. אם בקשה נדחית מטעמי בטיחות, היא עוברת אוטומטית למודל חלופי של Anthropic.
- **מגבלות:** העוזר לא מבצע פעולות באפליקציה (הוא מסביר איפה לעשות אותן), אין לו גישה לאינטרנט, והשיחה נשמרת רק כל עוד האפליקציה פתוחה.
- אפשר גם להגדיר את המפתח בקובץ `.env` (`ANTHROPIC_API_KEY`). מפתח שנשמר באפליקציה גובר עליו.

### אבטחה
האפליקציה מקשיבה רק ל-`127.0.0.1`, כלומר רק למחשב שלך, ואף אחד ברשת לא יכול להגיע אליה. בנוסף היא מוגנת מפני אתרים שנפתחים בדפדפן:
כל בקשה נושאת מפתח סודי שנוצר בכל הפעלה, וכתובות זרות נדחות.

### אם משהו לא עובד
| תקלה | פתרון |
|---|---|
| לא קופץ חלון התראה | ב*הגדרות* לוחצים "שלח התראת בדיקה". ב-Linux צריך `notify-send` (`sudo apt install libnotify-bin`). ב-Windows ו-Mac לבדוק שמצב "נא לא להפריע" כבוי. |
| נפתח בדפדפן ולא בחלון | זה בסדר. חלון מקומי דורש את החבילה האופציונלית `pywebview` (Windows/Mac מתקינים אותה לבד, ב-Linux: `pip install "pywebview[qt]"`). |
| "הפורט תפוס" | האפליקציה בוחרת פורט פנוי אחר לבד. `--port 9000` מכריח פורט. |
| משהו אחר | הלוג נמצא בתיקיית הנתונים, בקובץ `creator-desk.log`. |

> ⚠️ **מה נבדק:** כל הלוגיקה, ה-API והממשק נבדקו אוטומטית, והממשק גם רץ בדפדפן אמיתי (מצב בהיר/כהה, מסך צר, שימוש מלא).
> האפליקציה הארוזה והסקריפט ל-Linux הורצו בפועל. החלקים הספציפיים ל-**Windows ו-macOS** (חלון קופץ של המערכת, הפעלה אוטומטית,
> קבצי ההפעלה `.bat`/`.command` והחלון המקומי) נכתבו לפי התיעוד של כל מערכת אבל **לא הורצו על מחשב כזה**. אם משהו שם לא עובד, אפשר לתקן בקלות.

## 🚀 הפעלה ראשונה (בערך 5 דקות)

1. **יוצרים בוט בטלגרם:** פותחים שיחה עם [@BotFather](https://t.me/BotFather), שולחים `/newbot`, בוחרים שם, ומעתיקים את ה-**token**.
2. **מתקינים** (צריך Python 3.10 ומעלה):
   ```bash
   cd creator-bot
   python -m venv .venv
   source .venv/bin/activate        # ב-Windows:  .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. **מגדירים:** מעתיקים את `.env.example` ל-`.env` ומדביקים את הטוקן בשורה `TELEGRAM_BOT_TOKEN=`.
4. **מריצים:**
   ```bash
   python -m creator_bot
   ```
5. **מתחילים:** פותחים את הבוט בטלגרם ושולחים `/start`.
   🔒 מי ששולח `/start` ראשון הופך לבעלים של הבוט, וכל השאר נחסמים.

## ⏰ שהבוט ירוץ כל הזמן

כדי שהתזכורות יגיעו, הבוט צריך לרוץ כל הזמן. כמה אפשרויות:

- **המחשב שלך** – הכי פשוט להתחלה, אבל תזכורות יגיעו רק כשהמחשב דולק.
- **Raspberry Pi או מחשב ביתי שתמיד דלוק.**
- **שרת קטן בענן (VPS)** או כל שירות שמריץ קונטיינרים של Docker. הבוט צורך מעט מאוד משאבים.

עם Docker:

```bash
cd creator-bot
docker build -t creator-bot .
docker run -d --name creator-bot --restart unless-stopped \
  --env-file .env -v "$PWD/data:/app/data" creator-bot
```

הנתונים נשמרים בקובץ SQLite בתיקייה `data/`. כדאי לגבות אותו, או להפעיל את מודול הדרייב שעושה את זה אוטומטית.

## 📈 חיבור נתוני הערוץ (לא חובה)

1. נכנסים ל-[Google Cloud Console](https://console.cloud.google.com/), יוצרים פרויקט ומפעילים את **YouTube Data API v3**.
2. ב-**Credentials** יוצרים **API key**.
3. ב-`.env` ממלאים `YOUTUBE_API_KEY=...` ו-`YOUTUBE_CHANNEL=@הערוץ_שלך` (או מזהה ערוץ שמתחיל ב-`UC`).

הבוט שומר תמונת מצב פעם ביום. אחרי יום-יומיים מתחילים לראות שינויים, ויעד הצפיות החודשי מתחיל לעבוד.

## 📁 חיבור גוגל דרייב (לא חובה)

1. באותו פרויקט ב-Google Cloud מפעילים את **Google Drive API**.
2. מגדירים **OAuth consent screen** (User type: External) ומוסיפים את עצמך כ-Test user.
3. ב-**Credentials** יוצרים **OAuth client ID** מסוג **Desktop app**, ומעתיקים את ה-ID וה-Secret ל-`.env`.
4. מריצים פעם אחת (במחשב עם דפדפן):
   ```bash
   python -m creator_bot.tools.google_auth
   ```
   מאשרים בדפדפן ומעתיקים את השורה `GOOGLE_REFRESH_TOKEN=...` ל-`.env`.
5. **חשוב:** כשהאפליקציה במצב *Testing*, גוגל מבטלת את הטוקן אחרי 7 ימים. כדי שזה לא יקרה מעבירים אותה ל-**In production**
   (בהרשאה `drive.file` שבה הבוט משתמש לא אמור להידרש תהליך אימות של גוגל).

הבוט משתמש בהרשאה המצומצמת `drive.file`, כלומר הוא רואה **רק קבצים ותיקיות שהוא עצמו יצר**, ולא את שאר הדרייב שלך.

## ➕ הוספת פיצ'ר חדש

יוצרים קובץ ב-`creator_bot/modules/`, לדוגמה מודול שמציע לחתוך שורט מכל סרטון שעלה:

```python
# creator_bot/modules/shorts.py
from ..core import ui
from ..core.module import MenuButton, Module


class ShortsModule(Module):
    name = "shorts"

    def setup(self):
        self.core.events.on("video.published", self.suggest_short)

    def menu_buttons(self):
        return [MenuButton("📱 שורטס", self.show, order=35)]

    async def show(self, update, context):
        await ui.reply(update, "📱 כאן יופיעו רעיונות לשורטס")

    async def suggest_short(self, video, **_):
        await self.core.notify(f"📱 טיפ: לחתוך שורט מתוך <b>{ui.esc(video.title)}</b> ולהביא לו עוד צפיות!")
```

ומוסיפים את `ShortsModule` לרשימה `ALL_MODULES` בקובץ `creator_bot/modules/__init__.py`. זהו.

**רעיונות להמשך:** סנכרון עם Google Calendar, זיהוי אוטומטי של סרטון שעלה ביוטיוב (ואז סימון שלב ההעלאה),
דוח חודשי עם גרפים, הצעות לכותרות ולתמונות ממוזערות בעזרת AI, ודשבורד ווב.
